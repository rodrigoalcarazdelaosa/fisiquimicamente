{{- $html := string . -}} {{- range findRE `(?s)]*>.*?` $html -}} {{- $math := . -}} {{- range findRESubmatch `([^<]*)` $math 1 -}} {{- $display := findRE `^]* display="block"` $math 1 -}} {{- $delimiter := cond (ne (len $display) 0) "$$" "$" -}} {{- $html = replace $html $math (printf "%s%s%s" $delimiter (index . 1) $delimiter) -}} {{- end -}} {{- end -}} {{- return $html -}}
